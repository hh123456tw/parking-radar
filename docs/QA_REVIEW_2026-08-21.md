## 已修正

1. 行事曆 JSON 含損壞資料列時會讓查詢回傳 503：現在會忽略無效列並依星期降級。
2. 舊資料 migration 後 `facility_source` 為 SQL NULL 時，官方場站型態無法立即覆蓋：現在把 NULL 視為 unknown。
3. 週末／假日費率可能誤用不含星期資訊的結構化平日價：現在遇到明確假日差價時顯示官方文字的保守範圍。
4. Flask 本機環境缺少 `Service-Worker-Allowed: /`：現在 `/static/sw.js` 可控制首頁範圍。

每項修正都有獨立回歸測試與 commit。
