# 首選停車場費率折疊區設計

## 目標

在三張首選停車場卡片中提供官方完整費率與營業時間，讓使用者在決定前可以查看價格資訊，同時避免長篇官方文字撐高所有卡片或干擾即時空位、距離與主要操作。

## 範圍

- 僅調整首選停車場卡片，不改動「其他附近場站」精簡列表。
- 使用既有 API 已回傳的 `fee_info` 與 `service_time`，不修改資料庫、資料收集器、API 格式或推薦公式。
- 官方費率內容完整保留，不摘要、不推算停車成本，也不嘗試解析平假日或累進費率。

## 介面設計

每張首選卡片在推薦原因與操作按鈕之間加入原生 `<details>` 元件，預設收合，摘要文字為「費率與營業時間」。展開後依序顯示：

1. 「官方費率」標籤與 `fee_info` 完整文字。
2. 「營業時間」標籤與 `service_time` 完整文字。

文字必須經既有 `escapeHtml` 處理。內容使用保留換行、自動斷行及任意長字串換行的樣式；展開內容最高 160px，超出時在區塊內垂直捲動，避免卡片無限制增高。若欄位為空值或只有空白，對應內容顯示「官方未提供」。

折疊區沿用現有深色介面，以低對比邊框和次要文字色呈現，不與「開啟 Google 地圖」及「查看空位趨勢」兩個主要操作競爭。使用原生 `<details>`／`<summary>`，保留鍵盤操作與展開狀態語意。

## 資料流與錯誤處理

`collector.py` 已將官方 `payex` 儲存為 `fee_info`，`app.py` 的公開候選資料也已輸出 `fee_info` 與 `service_time`。前端 `primaryCard` 直接讀取這兩個欄位；缺值只影響文字顯示，不應阻止卡片渲染，也不新增網路請求。

## 驗證

- 前端契約測試確認首選卡包含折疊元件、官方費率與營業時間欄位，並保留 HTML escaping。
- 樣式契約確認長文字具備最高高度、內部捲動、保留換行與強制斷行。
- 執行 JavaScript 語法檢查與完整 pytest 測試，確認既有推薦、API 和頁面契約沒有回歸。

## 不包含

- 費率加入推薦分數或排序。
- 根據停車時數估算費用。
- 將官方費率解析成結構化價格。
- 在地圖、歷史圖或其他附近場站重複顯示費率。
