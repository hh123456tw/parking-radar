# ADR 0002：先排除高風險場站，再比較步行距離

- 狀態：採用
- 日期：2026-08-04

## 背景

只依距離排序時，最近但只剩一兩格的停車場會排在第一名；駕駛抵達時很可能已經客滿，反而浪費時間。

## 決策

1. 排除無效資料（官方特殊值 `-9`、`-11` 等）與搜尋半徑 1.5 公里外的場站。
2. 剩餘不超過 3 格列為不建議；不超過 10 格或空位率低於 10% 列為備選；其餘列為可以前往。
3. 「可以前往」的場站優先，同一級內依 OpenRouteService 實際步行時間排序；路線服務失敗時退回直線距離並標示來源。
4. 有目的地座標時只用半徑篩選，不再限制行政區，避免漏掉區界對面的場站。

## 影響

- 首選的意義是「現在去大概停得到、且停完走最少路」。
- 門檻是可解釋的固定數字，使用者看得懂排序理由。
- 代價：門檻不會因時段自動調整；歷史資料只作趨勢參考，不參與排序。
