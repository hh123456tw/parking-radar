# ADR 0001：AI 只理解問題，推薦由固定規則決定

- 狀態：採用
- 日期：2026-08-03

## 背景

使用者習慣用自然語言描述目的地（「今晚六點去市政府」），但推薦結果必須可重現、可測試，並能向使用者說明原因。

## 決策

Gemini 只負責把自然語言轉成結構化意圖（目的地、行政區、抵達時間、地點候選），輸出受 Pydantic schema 約束，行政區限定為臺北市 12 區。
地址一律再經 Nominatim 驗證，停車場篩選、風險分級與排序全部由 `analysis.py` 的 Python 規則完成。

## 影響

- 同樣的輸入得到同樣的推薦，規則有單元測試保護。
- 模型無法產生 SQL、座標或推薦名單，降低 prompt injection 的影響範圍。
- Gemini 無法使用時，手動查詢仍走同一套規則，功能不中斷。
- 代價：自然語言只能表達 schema 允許的欄位，無法處理超出範圍的需求。
